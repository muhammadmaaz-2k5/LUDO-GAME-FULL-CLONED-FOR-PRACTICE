# 🎲 Pak Ludo - Frontend Web Application

Modern dark-themed multiplayer frontend for Pak Ludo built with React, Vite, Tailwind CSS, and Radix UI.

## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start Vite development server:**
   ```bash
   npm run dev
   ```

3. **Open browser:**
   Navigate to `http://localhost:5173`.
